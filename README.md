# SAP-snarvei for StreamBIM

En kompakt widget med Statkraft-navn og en tydelig «Åpne SAP»-knapp.
Hele kortet er klikkbart. SAP åpnes i ny fane; eventuell innlogging skjer hos SAP.

## Bruk

Åpne `index.html` lokalt, eller legg filen på et HTTPS-webhotell som tillater innbygging i StreamBIM.
Ingen installasjon, bygging eller eksterne avhengigheter kreves.

SAP-adressen er angitt i `href` på lenken med klassen `launch`.
Alle parametrene i den oppgitte adressen er bevart.

Widgetens utseende og lenkemål er kontrollert lokalt. Innlogging og navigasjon inne i SAP er ikke testet.
Prosjektet er offentlig. GitHub Pages: https://terjefjeldberg.github.io/sap-snarvei-widget/
